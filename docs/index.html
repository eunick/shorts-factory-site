Shorts Factory

A desktop video production tool that creates short, vertical educational videos about science facts and curiosities, then publishes the finished videos to the creator's own TikTok account.

What it does

Shorts Factory runs on the operator's own computer. For each topic in its queue it:

  1. Writes a script: a short narration and shot list about a single fact, written by a locally hosted language model.
  2. Generates media: animated visuals and a narration voice track, created with AI models running on the same computer.
  3. Assembles the video: combines the clips, narration and burned-in captions into a 9:16 video of 45 to 60 seconds, and writes a suggested caption and hashtags.
  4. Publishes on request: in the Shorts Factory Publisher (a password-protected page on this site), the creator picks a finished video, reviews the preview and caption, chooses who can view it and which interactions to allow, and clicks Post to TikTok.

How the TikTok integration works

Shorts Factory uses TikTok's Login Kit to ask the account owner for permission and the Content Posting API to publish videos.

  • The account owner signs in on TikTok's own authorization page and approves access. Shorts Factory never sees the TikTok password.
  • Two permissions are requested: user.info.basic, to show the connected account's display name and avatar, and video.publish, to post videos to that account.
  • Before each post, Shorts Factory asks TikTok for the creator's display name, username, profile photo and available posting options, so the Publisher can show which account the video will be posted to and offer only the settings TikTok allows. This information is displayed, not stored.
  • Every post is made only when the creator clicks Post to TikTok. Nothing is posted automatically, and no visibility setting is pre-selected.
  • Shorts Factory does not read the account's followers, messages, likes or existing videos.
  • Access tokens are stored only on the operator's computer and are used only to call TikTok's API.
  • Access can be removed at any time with the Disconnect button in the Publisher, which revokes it with TikTok and deletes the stored tokens, or from the connected apps settings in TikTok.

Who it is for

Shorts Factory is an independent project developed and operated by Derrick Caluag. It publishes original, AI-generated educational content to the TikTok account the operator connects. It is not a hosted service: there is no sign-up, no user accounts and no server that stores user data.

Content

All visuals and narration are generated by AI models. Videos are designed to present one surprising, verifiable fact each, and the content rules exclude real named people and brand names. Shorts Factory does not repost or re-upload other creators' content.
